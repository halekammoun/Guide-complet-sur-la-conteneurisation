## task 1
```text
1. Running Simple Containers
ACME Corporation wants to demonstrate a simple microservice application using containers. As an initial demonstration, deploy an Nginx container.

Start a container that meets the following requirements:
Use the image docker.io/library/nginx:latest
The container must be named acme-demo-html
The container must run in detached mode
Expose container port 80 on host port 8001
Map the host directory $HOME/workspace1/acme-nginx-html to the container path /usr/share/nginx/html
The website must return: Hello World NginX
Verification
curl localhost:8001 -> Hello World NginX
```

## task 3
Le port de l’hôte (host port) ne peut pas être associé simultanément à deux services différents sur la même adresse IP (notre host). Or, les deux conteneurs utilisent le même mapping -p 8003:8080, ce qui crée un conflit, car le port 8003 de l’hôte est déjà utilisé par le premier conteneur. Il faut donc le premier conteneur pour créer le second.
```bash
podman run -d --name acme_nginx_container_1 -e RESPONSE="Welcome_ACME_Nginx_Container_1" -p 8080:8003 quay.io/myacme/welcome
```
```bash
curl localhost:8003
```
ça donne `Welcome_ACME_Nginx_Container_1`

```bash
podman stop acme_nginx_container_1
```
```bash
podman run -d --name acme_nginx_container_2 -e RESPONSE="Welcome_ACME_Nginx_Container_2" -p 8080:8003 quay.io/myacme/welcome
```
ça donne `Welcome_ACME_Nginx_Container_2`
