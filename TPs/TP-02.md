## task 1
```bash
podman run -d --name acme-demo-html -p 8001:80 -v $HOME/workspace1/acme-nginx-html:/usr/share/nginx/html:Z docker.io/library/nginx:latest
```
sans :Z ça nous donne l'erreur Forbidden 403
```bash
podman ps 
```
Tester Port Mapping

```bash
curl localhost:8001
```
```bash
podman exec <idcontainer> curl localhost:80
```
ou bien entrer avec shell puis faire le curl 
```bash
podman exec -it <idcontainer> bash
```
```bash
curl localhost:80
```
## task 2
```bash
podman run -d --name acme-demo-nginx -p 8002:80 docker.io/library/nginx:latest
```
```bash
podman cp $HOME/workspace2/acme-nginx-web/html/. <idcontainer>:/usr/share/nginx/html

ou

podman cp $HOME/workspace2/acme-nginx-web/html/index.html <idcontainer>:/usr/share/nginx/html

ou

podman cp $HOME/workspace2/acme-nginx-web/html/* <idcontainer>:/usr/share/nginx/html
```
si vous oubiez de copier le contenu et pas le répertoire nginx ne trouve pas notre page web et affiche la page web par défaut le path sera: `/usr/share/nginx/html/html/index.html`
```bash
podman cp $HOME/workspace2/acme-nginx-web/conf/nginx.conf <idcontainer>:/etc/nginx/conf.d/default.conf
```
```bash
podman exec <idcontainer> nginx -s reload
ou 
podman exec -it <idcontainer> bash
nginx -s reload
```
